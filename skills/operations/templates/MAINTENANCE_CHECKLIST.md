# Checklist de maintenance

## Hebdomadaire / régulier
- [ ] Vérifier alertes.
- [ ] Vérifier espace disque.
- [ ] Vérifier dernier backup.
- [ ] Examiner erreurs significatives.

## Mensuel / périodique
- [ ] Vérifier mises à jour de sécurité.
- [ ] Vérifier certificats.
- [ ] Vérifier croissance DB/media.
- [ ] Vérifier tâches planifiées.
- [ ] Nettoyage prudent des artefacts.

## Trimestriel ou selon criticité
- [ ] Tester restauration.
- [ ] Relire runbooks.
- [ ] Vérifier comptes/permissions admin.
- [ ] Vérifier capacité serveur.
