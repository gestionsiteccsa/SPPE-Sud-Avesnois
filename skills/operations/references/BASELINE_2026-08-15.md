# Baseline Operations — 2026-08-15

## Django logging

Django utilise le système de logging Python et permet une configuration via `LOGGING`.

Référence :
https://docs.djangoproject.com/en/6.0/topics/logging/

## Django deployment

La checklist de déploiement couvre notamment :
- erreurs ;
- logging ;
- HTTPS ;
- cache ;
- base ;
- backups.

Référence :
https://docs.djangoproject.com/en/6.0/howto/deployment/checklist/

## PostgreSQL

PostgreSQL fournit des outils et vues pour observer :
- activité ;
- connexions ;
- requêtes ;
- locks.

Références :
https://www.postgresql.org/docs/current/monitoring.html
https://www.postgresql.org/docs/current/monitoring-stats.html

## Philosophie retenue

- observabilité proportionnée ;
- alertes actionnables ;
- logs sans secrets ;
- health checks simples ;
- monitoring ressources + backups ;
- runbooks pour incidents récurrents ;
- pas de stack Prometheus/Grafana imposée à un petit serveur.
