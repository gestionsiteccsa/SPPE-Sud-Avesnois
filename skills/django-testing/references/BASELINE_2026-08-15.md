# Baseline Django Testing — 2026-08-15

Ce document sert de contexte. Vérifier la documentation officielle correspondant aux versions réellement utilisées.

## Django

Django fournit un framework de test permettant notamment de :

- simuler des requêtes ;
- créer des données ;
- tester des vues ;
- vérifier le rendu et les réponses ;
- isoler la base de test.

La documentation distingue notamment l’usage de classes de tests selon le besoin transactionnel.

Références :
https://docs.djangoproject.com/en/6.0/topics/testing/
https://docs.djangoproject.com/en/6.0/topics/testing/overview/

## pytest

pytest vise des tests petits et lisibles tout en pouvant gérer des suites complexes.

Il fournit notamment :

- fixtures ;
- paramétrisation ;
- marks ;
- assertions simples.

Références :
https://docs.pytest.org/en/stable/
https://docs.pytest.org/en/stable/explanation/goodpractices.html
https://docs.pytest.org/en/stable/how-to/fixtures.html
https://docs.pytest.org/en/stable/how-to/parametrize.html

## pytest-django

pytest-django ajoute l’intégration Django et contrôle explicitement l’accès DB.

Référence :
https://pytest-django.readthedocs.io/en/latest/database.html

## Philosophie retenue

- TDD pragmatique ;
- tests orientés comportement ;
- permissions négatives systématiques lorsqu’elles sont importantes ;
- base réelle pour les comportements SQL importants ;
- fixtures petites et composables ;
- paramétrisation pour éviter duplication ;
- couverture comme indicateur, pas comme but.
