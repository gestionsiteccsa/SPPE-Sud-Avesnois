## Principles retained
- mêmes commandes local/CI ;
- environnement propre ;
- PostgreSQL si la prod en dépend ;
- secrets séparés ;
- staging avant prod selon risque ;
- health check après deploy ;
- rollback documenté ;
- production protégée ;
- pas de déploiement dangereux automatisé par défaut.
