# Checklist Privacy

## Données
- [ ] Données personnelles identifiées.
- [ ] Minimisation.
- [ ] Finalité.
- [ ] Base légale à valider/identifiée.
- [ ] Données sensibles analysées.

## Accès
- [ ] Moindre privilège.
- [ ] Permissions objet.
- [ ] API minimise les champs.
- [ ] Admin limite l’exposition.

## Conservation
- [ ] Durée.
- [ ] Purge/anonymisation.
- [ ] Suppression de compte.
- [ ] Backups pris en compte.

## Droits
- [ ] Accès.
- [ ] Rectification.
- [ ] Effacement.
- [ ] Portabilité/opposition/limitation si applicables.

## Tiers
- [ ] Sous-traitants.
- [ ] Hébergement.
- [ ] Email/analytics.
- [ ] Transferts internationaux analysés.

## Traceurs
- [ ] Cookies classés.
- [ ] Consentement si nécessaire.
- [ ] Refus aussi simple.
- [ ] Pas de chargement prématuré.

## Technique
- [ ] Logs minimisés.
- [ ] Tests.
- [ ] Documentation.
- [ ] Validation DPO/juridique signalée si nécessaire.
