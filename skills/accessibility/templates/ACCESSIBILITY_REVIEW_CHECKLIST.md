# Checklist Accessibilité

## Structure
- [ ] Landmarks.
- [ ] H1/titres.
- [ ] HTML sémantique.
- [ ] Langue page.

## Clavier
- [ ] Tous les contrôles atteignables.
- [ ] Activation clavier.
- [ ] Focus visible.
- [ ] Pas de piège.
- [ ] Retour focus correct après modal.

## Formulaires
- [ ] Labels.
- [ ] Required clair.
- [ ] Instructions.
- [ ] Erreurs associées.
- [ ] Résumé erreurs si complexe.

## Visuel
- [ ] Contraste.
- [ ] Pas couleur seule.
- [ ] Zoom/reflow.
- [ ] Cibles tactiles.
- [ ] Reduced motion.

## Médias
- [ ] Alt text.
- [ ] Icônes nommées.
- [ ] SVG traités correctement.

## Composants
- [ ] ARIA nécessaire et valide.
- [ ] Name/role/value.
- [ ] États dynamiques annoncés.
- [ ] Pattern clavier adapté.

## Tests
- [ ] Scanner automatique si configuré.
- [ ] Test clavier.
- [ ] Vérification manuelle des pages critiques.
