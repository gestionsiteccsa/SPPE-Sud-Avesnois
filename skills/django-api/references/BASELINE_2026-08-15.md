# Baseline Django API — 2026-08-15

Ce document donne les références de conception. Vérifier les versions réellement installées.

## Django REST Framework

DRF est un toolkit pour construire des Web APIs.

Référence :
https://www.django-rest-framework.org/

## Authentication

DRF exécute l’authentification au début du traitement, avant permissions et throttling.

Référence :
https://www.django-rest-framework.org/api-guide/authentication/

## Permissions

Les permissions déterminent si une requête doit être accordée ou refusée.

Les permissions objet nécessitent une attention particulière sur les listes et créations.

Référence :
https://www.django-rest-framework.org/api-guide/permissions/

## Pagination

DRF propose plusieurs stratégies de pagination.

Référence :
https://www.django-rest-framework.org/api-guide/pagination/

## Filtering

Le filtrage passe notamment par `get_queryset()` et peut être complété par des filter backends.

Référence :
https://www.django-rest-framework.org/api-guide/filtering/

## Throttling

Le throttling DRF contrôle le taux de requêtes mais ne doit pas être présenté comme une protection absolue contre toutes les attaques volumétriques.

Référence :
https://www.django-rest-framework.org/api-guide/throttling/

## Versioning

DRF fournit plusieurs schémas de versioning basés sur URL ou headers.

Référence :
https://www.django-rest-framework.org/api-guide/versioning/

## ViewSets

Les ViewSets regroupent la logique d’un ensemble de vues liées.

Référence :
https://www.django-rest-framework.org/api-guide/viewsets/

## Testing

DRF fournit des helpers de test spécifiques aux requêtes API.

Référence :
https://www.django-rest-framework.org/api-guide/testing/

## Sécurité Django

Toute donnée contrôlée par l’utilisateur doit être considérée non fiable.

Référence :
https://docs.djangoproject.com/en/6.0/topics/security/
