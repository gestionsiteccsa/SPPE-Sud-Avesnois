# Checklist Documentation

## Feature
- [ ] Objectif compréhensible.
- [ ] Acteurs.
- [ ] Règles métier.
- [ ] Permissions.
- [ ] Cas particuliers.
- [ ] Technique utile.
- [ ] Tests critiques.

## Architecture
- [ ] Overview cohérent.
- [ ] Décision structurante documentée.
- [ ] Modèles/relations à jour.
- [ ] Mermaid lisible.

## Navigation
- [ ] Page accessible depuis index/navigation.
- [ ] Liens connexes.
- [ ] Aucun lien cassé évident.
- [ ] Pas de page orpheline importante.

## Projet
- [ ] README si installation/config changée.
- [ ] `.env.example` si variable ajoutée.
- [ ] CHANGELOG si changement notable.
- [ ] PROJECT_TASKS cohérent.

## Qualité
- [ ] Français clair.
- [ ] Pas de duplication excessive.
- [ ] Pas de secret.
- [ ] Pas de fonctionnalité future décrite comme disponible.
- [ ] Commandes réellement valides.
