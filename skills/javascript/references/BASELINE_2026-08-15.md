# Baseline JavaScript — 2026-08-15

Toujours vérifier les contraintes de navigateurs et l’outillage réellement utilisés.

## JavaScript modules — MDN
https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules

Les modules ES permettent de découper le code avec `import` et `export`.

## Fetch API — MDN
https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch

Fetch est une API Promise-based pour effectuer des requêtes HTTP.

Important : une réponse HTTP 4xx/5xx ne provoque pas nécessairement un rejet réseau ; vérifier `response.ok`.

## Async JavaScript — MDN
https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Async_JS

Les Promises et `async`/`await` permettent de gérer les tâches asynchrones sans bloquer l’interface.

## DOM events — MDN
https://developer.mozilla.org/en-US/docs/Web/API/Document_Object_Model/Events

Les événements DOM permettent de réagir aux interactions et changements.

## Django CSRF
https://docs.djangoproject.com/en/6.0/howto/csrf/

Pour les requêtes AJAX/fetch unsafe avec sessions Django, conserver la protection CSRF et transmettre le token selon la configuration.

## OWASP DOM XSS
https://cheatsheetseries.owasp.org/cheatsheets/DOM_based_XSS_Prevention_Cheat_Sheet.html

Éviter d’insérer des données non fiables dans des sinks HTML comme `innerHTML`.

## Principes retenus

- JavaScript natif d’abord ;
- modules ES ;
- fetch + async/await ;
- CSRF Django conservé ;
- `textContent`/DOM APIs sûres avant `innerHTML` ;
- aucun secret/token session dans localStorage ;
- progressive enhancement ;
- accessibilité obligatoire ;
- bundler seulement si besoin réel.
