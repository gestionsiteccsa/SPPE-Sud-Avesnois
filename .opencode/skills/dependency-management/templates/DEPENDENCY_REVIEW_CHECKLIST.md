# Checklist dépendances

## Ajout
- [ ] Besoin réel.
- [ ] Alternative standard/Django vérifiée.
- [ ] Nom/source vérifiés.
- [ ] Package maintenu.
- [ ] Compatibilité.
- [ ] Licence analysée si structurante.
- [ ] Sécurité analysée.

## Reproductibilité
- [ ] Manifeste à jour.
- [ ] Lock/résolution à jour.
- [ ] Installation propre testée.
- [ ] Runtime/dev correctement séparés.

## Validation
- [ ] Tests pertinents.
- [ ] Audit sécurité.
- [ ] Pas de secret.
- [ ] Déploiement compatible.
- [ ] Documentation si nécessaire.

## Maintenance
- [ ] Pins temporaires documentés.
- [ ] Packages abandonnés suivis.
- [ ] Versions EOL surveillées.
