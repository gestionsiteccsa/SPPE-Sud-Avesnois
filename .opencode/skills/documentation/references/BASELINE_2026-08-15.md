# Baseline Documentation — 2026-08-15

Vérifier les versions réellement utilisées lorsque la documentation dépend d’un outil.

## MkDocs

MkDocs est un générateur de site statique dédié à la documentation de projet.

Ses sources sont en Markdown et sa configuration principale est YAML.

Il permet une navigation structurée via `nav`.

Références :
https://www.mkdocs.org/
https://www.mkdocs.org/user-guide/writing-your-docs/
https://www.mkdocs.org/user-guide/configuration/

## Mermaid

Mermaid permet de créer des diagrammes à partir d’une syntaxe textuelle versionnable.

Types particulièrement utiles au projet :
- flowcharts ;
- sequence diagrams ;
- entity relationship diagrams ;
- class diagrams.

Références :
https://mermaid.js.org/intro/syntax-reference.html
https://mermaid.js.org/syntax/flowchart.html
https://mermaid.js.org/syntax/sequenceDiagram.html
https://mermaid.js.org/syntax/entityRelationshipDiagram.html

## Django

Django organise ses fonctionnalités en applications pouvant contenir notamment modèles, vues, templates, URLs et static files.

Les modèles représentent la source structurante des données.

Références :
https://docs.djangoproject.com/en/6.0/ref/applications/
https://docs.djangoproject.com/en/6.0/topics/db/models/

## Changelog

Keep a Changelog recommande un journal organisé des changements notables, plutôt qu’un dump de commits.

Référence :
https://keepachangelog.com/

## Philosophie retenue

- documentation Markdown comme source de vérité ;
- MkDocs optionnel comme couche de présentation ;
- Mermaid pour les schémas versionnables ;
- documentation en français ;
- mise à jour automatique avec les features ;
- pas de documentation exhaustive de fonctions triviales ;
- changelog centré sur les changements notables.
