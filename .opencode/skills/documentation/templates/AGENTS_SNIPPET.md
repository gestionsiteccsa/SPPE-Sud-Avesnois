## Documentation

- Charger `documentation` pour toute feature importante ou changement structurant.
- La documentation est mise à jour automatiquement : l’utilisateur ne doit pas avoir à le demander.
- La documentation du projet est en français sauf décision explicite contraire.
- Maintenir `docs/`, `README.md`, `CHANGELOG.md` et les décisions d’architecture selon l’impact réel.
- Utiliser Mermaid pour les relations et workflows lorsque cela améliore la compréhension.
- Ne pas documenter chaque fonction triviale.
- Toute page doit refléter le code réellement livré.
