# Checklist Tailwind

## Version / build
- [ ] Version connue.
- [ ] Syntaxe/config adaptée à cette version.
- [ ] Commande dev.
- [ ] Commande prod.
- [ ] Build propre réussi.

## Source scanning
- [ ] Templates Django détectés.
- [ ] JS détecté si nécessaire.
- [ ] Pas de classes dynamiques fragiles.
- [ ] Safelist ciblée seulement si nécessaire.

## Design
- [ ] Tokens cohérents.
- [ ] Valeurs arbitraires limitées.
- [ ] Composants existants réutilisés.
- [ ] Pas de duplication massive.
- [ ] CSS custom justifié.

## Responsive
- [ ] Mobile.
- [ ] Intermédiaire.
- [ ] Desktop.

## Accessibilité
- [ ] Contraste.
- [ ] Focus visible.
- [ ] Hover + focus.
- [ ] États disabled/error.
- [ ] HTML sémantique conservé.

## Dark mode
- [ ] Vérifié si actif.
- [ ] Contrastes.
- [ ] Contrôles natifs.
- [ ] Pas de flash gênant si toggle.

## Projet
- [ ] Static pipeline cohérent.
- [ ] CI/CD mis à jour si nécessaire.
- [ ] Documentation à jour.
