# Baseline technique — mise à jour 2026-08-15

Ce fichier donne du contexte au skill. Il ne doit pas remplacer une vérification des documentations officielles lors d’une future initialisation.

## Django

Au 15 août 2026 :

- Django 6.1 est la dernière version stable officielle.
- Django 6.0 reste supporté jusqu’en avril 2027.
- Django 5.2 LTS reste en support étendu jusqu’en avril 2028.
- Django 6.2 LTS est prévu pour avril 2027.

Le skill ne doit donc pas imposer une version en dur à tous les futurs projets.

## Principes officiels retenus

- Vérifier la checklist de déploiement Django avant production.
- Changer `AUTH_USER_MODEL` en cours de projet est complexe : la décision doit être prise tôt lorsqu’un custom user est nécessaire.
- Référencer le modèle utilisateur via `settings.AUTH_USER_MODEL` / `get_user_model()`.
- PostgreSQL est officiellement supporté par Django.
- Les migrations font partie du mécanisme normal de propagation des changements de modèles.
- Ruff peut assurer lint et formatage et s’intégrer à pre-commit.
- pytest recommande l’isolation via environnement virtuel et fournit des pratiques de structuration des tests.
- OpenCode découvre les skills via `skills/<name>/SKILL.md`.
- `AGENTS.md` contient les instructions persistantes propres au dépôt.
