# Baseline Git Quality — 2026-08-15

## Ruff

Ruff fournit un linter et un formatter Python et possède une intégration officielle pre-commit.

Références :
https://docs.astral.sh/ruff/
https://docs.astral.sh/ruff/integrations/
https://docs.astral.sh/ruff/formatter/

## pre-commit

pre-commit permet de déclarer des hooks versionnés et de les exécuter automatiquement avant des opérations Git.

Référence :
https://pre-commit.com/

## Django migrations

Django considère les migrations comme un système de versionnement du schéma.

`makemigrations --check` retourne un statut non zéro lorsqu’il existe des changements de modèles sans migration.

Références :
https://docs.djangoproject.com/en/6.0/topics/migrations/
https://docs.djangoproject.com/en/6.0/ref/django-admin/

## Django deploy check

La checklist de déploiement Django recommande l’utilisation de `check --deploy`.

Référence :
https://docs.djangoproject.com/en/6.0/howto/deployment/checklist/

## GitHub secret scanning

GitHub Push Protection peut empêcher l’envoi de secrets détectés.

Références :
https://docs.github.com/en/code-security/concepts/secret-security/push-protection
https://docs.github.com/en/code-security/secret-scanning/about-secret-scanning

## Philosophie retenue

- contrôles rapides au commit ;
- contrôles plus complets au push/CI ;
- aucun commit/push automatique ;
- blocage sur problèmes critiques ;
- pas de mise à jour automatique des dépendances juste avant push.
