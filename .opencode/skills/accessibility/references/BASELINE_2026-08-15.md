## RGAA
Référentiel officiel français à vérifier sur la source gouvernementale au moment de l’audit.

Principes retenus :
- HTML natif d’abord ;
- clavier obligatoire ;
- focus visible ;
- labels associés ;
- ARIA uniquement si nécessaire ;
- automated testing + manual testing ;
- ne pas déclarer une conformité légale uniquement via outils automatiques.
