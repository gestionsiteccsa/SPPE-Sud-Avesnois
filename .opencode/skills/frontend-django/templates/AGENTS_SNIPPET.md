## Frontend Django

- Charger `frontend-django` pour les pages HTML, formulaires, templates, static files et interactions JavaScript légères.
- Privilégier HTML sémantique et fonctionnalités natives avant un composant custom.
- JavaScript doit améliorer l’expérience sans remplacer inutilement le fonctionnement serveur.
- Toute validation de sécurité reste côté serveur.
- Les formulaires doivent avoir labels, erreurs compréhensibles et fonctionnement clavier.
- Ne pas introduire un framework frontend lourd sans besoin explicite et décision d’architecture documentée.
